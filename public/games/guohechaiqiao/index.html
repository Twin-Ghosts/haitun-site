联机对局

📖 规则速览 / 怎么玩
目标：最后存活者获胜（其他人全部死亡）。
地图：中心岛 C + n 个基地 B1…Bn。每人起始占一个基地，位置对他人保密。每座基地初始有一座桥连向 C，桥有 2 点耐久，走满 2 次即永久坍塌。
每轮五选一（所有人同时暗选，全部提交后一起结算）：
  • 建桥：从你所在地，向一个「与你现在没有直连桥」的地点建一座桥（耐久 2）。不能连续两轮建。
  • 移动：沿相邻的桥走到对岸，消耗该桥 1 点耐久。
  • 拆桥：拆掉「你与某地点之间的桥」。可以赌它本回合刚被建成；若结算时它不存在，则这一手转为「不动」。不能连续两轮拆。
  • 猜杀：指名「一名玩家 + 一个地点」（只能是你所在地，或与你直连的相邻地点），断言他回合结束时在那里。猜中对方死，猜错自己死。
  • 不动：留在原地，但会公开暴露你的位置。
结算顺序：建桥 → 拆桥 → 移动（先手正序）→ 猜杀（先手倒序）→ 连通性死亡 → 反僵持 → 雷达。
死法（不只靠猜）：
  • 坠桥：你正要走的桥被拆掉、或被先手者走到坍塌 → 坠亡。
  • 孤立死：回合结束时你所在地不与任何地方相连 → 死。
  • 分割全灭：地图被拆成几块时，只有最强的一块存活（比①人数 ②占地数 ③是否含中心岛），其余全灭。
  • 力竭：连续两回合都「不动」，第二回合结束时死亡（不许一直观望）。
先手序：整局固定、公开。移动按正序（P1 先动），猜杀按倒序（Pn 先开枪）——移动占先的人猜杀反而落后，是一把双刃剑。
中心岛雷达（附赠，不占行动）：回合开始时人在 C 的玩家，可以额外指定一个基地，回合结束时得知那里此刻有几个人（只知道人数）。
核心杀招：推断出对手在 Bk，就去拆掉 Bk↔C 那唯一的桥——他若留下则孤立死，若正过桥则坠桥身亡。这就是「过河拆桥」。
