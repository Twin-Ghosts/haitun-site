新游戏骨架

这是空壳，不是游戏。复制整个 starter 目录，改名，再开始写。
  1. 把 public/dev/starter/ 整个复制成 public/dev/你的游戏名/，只在这个目录里加文件。
  2. 联机主题前缀用 dev/你的游戏名/v1/。主站是 cubetilt/v1/ 与 ghcq/v1/，两边主题不交叉，测试房间不会串进主站。
  3. 保留顶部的 <meta name="robots" content="noindex, nofollow">，别让搜索引擎收录半成品。
  4. 测试通了，再决定要不要「毕业」到 public/games/你的游戏名/ 并加进主站列表。毕业之前，主站文件一个字都不用改。
