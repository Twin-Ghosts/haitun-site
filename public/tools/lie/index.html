LIE 猜数字博弈策略

输入双方手牌计数与你的角色，查表给出均衡策略：出题者该按什么比例报哪个数字，猜测者何时该相信、何时该质疑。全部在浏览器内计算，不联网、不上传。

对方公开数字
本方手牌计数（数字 1~6 各有几张，填 0 / 1 / 2）
对方手牌计数（数字 1~6 各有几张，填 0 / 1 / 2）

规则：两人各自持有数字 1~6 的牌（同一数字最多 2 张）。出题者私信一个真实数字 a、对外报一个公开数字 b； 猜测者判断 a 是否等于 b——猜对则猜测者胜，否则出题者胜。先集齐 1~6 六种、或某数字凑到 3 张的一方告负。
策略从哪来：策略表由逆向归纳按信号博弈离线求解得到（提问者 36 个动作，猜测者看到公开数字后再决策）； 页面只做查表、概率矩阵展示与随机采样，不再做博弈求解。
精度：概率为离线均衡的近似值，同类数字之间均分；结果仅作策略参考。
局面出现概率：从双空开局、双方都按均衡策略对弈，前向传播估算出走到这一手牌结构的可能性；不可达的方向记为 0。
均衡外信号：若某个公开数字在当前局面的均衡策略里不会被报出，页面标注为「均衡外信号」；这类信号出现时该相信还是质疑不受策略约束，不给出相信概率。
